# SocialEcho Platform

SocialEcho is a social media platform built using the MERN stack (MongoDB, Express.js, React.js, and Node.js) with content moderation and community features.

## Live Deployment

### Frontend (React)

**Live Application:**
https://social-echo-platform.vercel.app/

### Backend API (Node.js + Express)

**API Server:**
https://socialecho-platform.onrender.com

### Database

**Database Provider:** MongoDB Atlas

## Technology Stack

* Frontend: React.js
* Backend: Node.js + Express.js
* Database: MongoDB Atlas
* State Management: Redux Toolkit
* Authentication: JWT
* Image Storage: Cloudinary
* Deployment:

  * Frontend: Vercel
  * Backend: Render
  * Database: MongoDB Atlas
